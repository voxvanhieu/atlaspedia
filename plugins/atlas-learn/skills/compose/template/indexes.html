How to use

Pick a tab, then type in the filter box to match any part of a caption, title, label, first line of code or term; every entry links to its page and section. Concepts list the glossary terms and every <dfn> definition on the pages, A–Z. Regenerate the data with python <PLUGIN_ROOT>/scripts/build_site_data.py <site> (also run by scaffold.py --sync) whenever pages change.
