Claude Code plugin · Learning workflow · Version 0.1.0

atlas-learn: learn a topic in four stages

An interview pins down what you want to learn, parallel researchers build a dossier of verified sources, and page writers turn it into an interactive site you can read offline. Written for anyone who learns from documentation and wants to trust the numbers in it.

Scope
4 stages · 9 subagents · 10 Python scripts
Audience
Claude Code users, beginner → researcher
Running example
The map-projections topic, 6 modules + a project
Format
Local HTML · works offline (diagrams, demos); maths, fonts & media need internet
