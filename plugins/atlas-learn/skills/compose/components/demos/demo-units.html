Model: map length \( l = D / N \) for a ground distance \( D \) at scale \( 1 : N \), the definition of a map scale [5]; one millimetre of map covers \( N \) mm of ground. Pick miles or inches in the unit menus: the sliders convert, the model still receives kilometres and centimetres (the base units the markup declares). Not modelled: the scale variation across a sheet (a projection's scale factor), paper margins. Plain scale arithmetic; no external source.
