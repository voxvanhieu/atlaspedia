How to read it

Colour marks the group of the module where a term is explained; a bigger node has more links. Zoom with the figure's buttons or Ctrl/⌘+scroll, drag to pan, double-click to reset. Terms that float alone at the edge are defined but never cross-referenced — a hint for the glossary's writer. The map is rebuilt from the pages by build_site_data.py (also run by scaffold.py --sync), so edit assets/glossary.json, not this page.

Trust & provenance

Assumptions and simplifications
  • Mentions are found by matching term names of four letters or more (plural allowed) inside definitions; they are hints, not curated links, and a term named in passing still counts.
  • The layout is a force-directed simulation with a fixed seed: the same data always gives the same picture, but distance carries no meaning beyond "linked terms sit close".
