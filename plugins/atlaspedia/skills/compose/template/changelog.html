Changelog

Every build and fix round of this site leaves one entry here, newest first: the date, the site version, what changed and which pages were touched. A page named in an entry shows last change with that date in its trust footer; every page footer carries the current version.

How to read it

An entry is one line of assets/changelog.json: { "date": "YYYY-MM-DD", "version": "1.0", "note": "…", "pages": ["m01-….html"] }. The compose stage appends one when a site is first built and one per fix round; a maintainer appends one by hand after editing pages, then runs scaffold.py --sync so assets/data.js and the footer stamps follow. The version comes from the site plan's Version header (site.json version); bump it with every entry that changes content.
