Measure the size budget of a real topic

Level 1 2 tools

Estimate a single-page topic from its brief, build it, and compare the estimate with the measured page size.

Procedure

  1. Run python scripts/estimate_size.py topics/<slug>/PLAN.md and record est_kb and fits from the RESULT line.
  2. Compose the page (/atlaspedia:compose <slug>) and record the size validate.py prints for index.html.
  3. Run bundle.py and record the bytes= value of the bundled file.
  4. Compute the estimate error as (measured − estimated) / estimated.

Before you start

  • The plan's research row is [x] — compose needs it.
  • Python 3.11+ and node are on PATH (without node the validator skips the script syntax check).
  • The topic folder is committed, so a failed run can be reverted.
