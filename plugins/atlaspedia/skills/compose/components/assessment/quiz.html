atlaspedia page writers have no web tools. Why?

  1. Because web searches would make the compose stage too slow to finish in one session.
  2. Because the dossier is the only source of facts, so every number on a page traces to a verified source.
  3. Because the sonnet model that writes most pages cannot call web tools in Claude Code.
If writers could search, a page could quote a number that no researcher checked and that another page states differently. Keeping research and writing apart means a missing fact becomes a gap that goes back to a researcher. Speed (A) is not the reason, and sonnet subagents can be given web tools (C); the field scout runs on sonnet with them.
