Model: ground distance \( D = l \, N \, s \) in km from a map length in mm [5]. Each input carries a tolerance (data-tol, percent); the run draws every input uniformly inside its band with a fixed seed, so the numbers repeat, and the worst case enumerates the eight corners. The tornado bars show each input alone at its low (↓) and high (↑) limit. Not modelled: ruler reading bias, the scale factor of the projection across the sheet. Plain error propagation; no external source.
