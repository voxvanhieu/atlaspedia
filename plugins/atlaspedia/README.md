# atlaspedia

The atlaspedia plugin for Claude Code: insight → verified research → an interactive documentation site, built in four gated stages. Every claim cites a real source; anything the sources do not establish is marked as missing, never guessed. That rule is the evidence policy (`references/evidence-policy.md`), and it governs every stage, agent, component and gate in this plugin.

The full quick-start guide, install instructions and screenshots-style walkthrough live in the repository root [`README.md`](../../README.md). The machine-level contracts for every file the plugin writes are in [`references/contracts.md`](references/contracts.md); component catalogs are under `skills/compose/components/`.
